# GuitarChat

NeoForge 1.21.1 мод: играешь на гитаре - персонаж выполняет действия.
Требует Simple Voice Chat.

## Сборка
```
gradle build
```
Готовый jar: build/libs/guitarchat-1.0.0.jar

## Управление
- G - открыть меню настроек (бинды нот, пороги, перекалибровка)
- При входе в мир мод 10 секунд калибрует порог шума - в это время молчи.

## Действия (binds)
none, jump, sprint, sneak, attack, use, inventory, drop, swap_offhand,
forward, back, left, right, hotbar_1 ... hotbar_9
